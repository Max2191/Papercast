# Papercast

Papercast converts scientific papers into structured summaries and listenable audio explanations using multimodal document parsing, scientific summarization, and neural text-to-speech.

## Current features

- PDF and arXiv paper ingestion
- Standard Docling and Granite-Docling document processing
- Extractive and PEGASUS-X summarization
- Technical narration preparation
- Neural text-to-speech output

## Limitations

- Large transformer models may be slow on CPU hardware
- Equation narration is currently approximate
- Complex papers may require processing in smaller page ranges
